# 整卡拖拽:正文区域不再支持文字选择

卡片的移动拖拽从「仅标题栏可拖」改为「整张卡片(含正文区域)可拖」,代价是正文文本不再可用指针选择(user-select: none)。

这是一个有意的取舍:统一且更大的拖拽热区(尤其 headless 卡片没有标题栏)优先于正文文本选择。正文本就只读(编辑走独立的 Dialog),文本选择的实际使用频率低。未来的维护者看到正文上的 user-select: none 不应将其当作 bug 修掉。

## Consequences

- 标题内联编辑(contentEditable)与各类按钮仍按原有 pointer-enter 挂起逻辑排除在拖拽热区之外。
- 断言「拖拽正文不移动卡片」的旧 e2e 用例需随行为变更同步反转。
