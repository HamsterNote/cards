# headless 卡片模式:持久化字段 + 开启时一次性写入正文

卡片画布支持 headless 卡片(隐藏标题栏、只展示正文)。headless 状态是卡片数据上的持久化布尔字段,随卡片一起序列化。

开启开关时,若卡片正文为空,会把标题**一次性写入正文数据**(而非渲染层派生),标题字段保留不变。这是有意的数据冗余:用户明确接受了「正文从此持有标题副本、关闭开关后正文不再自动清空」的代价,以换取实现与语义的简单直接——headless 卡片展示的就是正文数据本身,不存在「展示的文本不在数据里」的歧义。

## Considered Options

- **渲染层派生**(正文保持空,展示时回退到标题):数据更干净,但「看到的内容」与「数据内容」不一致,关闭开关时状态可逆却也更容易让外部消费方(导出、搜索)困惑。被否。
- **开启时写入正文并清空标题**:有损操作,关闭开关无法恢复标题。被否。

## Consequences

- headless 卡片的标题不可内联编辑(标题栏已隐藏),要改标题需先关闭开关。
- 链接按钮、aria-label 等仍使用标题字段,不受 headless 影响。
